# MRK content architecture and publishing roadmap

This roadmap is intentionally **not** a batch of automatically published articles. Publish a service, project or article only after the owner verifies that it represents work MRK can genuinely provide or has actually completed.

## Service architecture

Create parent Service Area terms for Web Development, App & Software, Digital Services, PLC & Automation, Arduino / ESP32 / IoT and IT Services. Add a Service entry only for confirmed offerings. The requested service catalogue is mapped below for editorial planning:

- **Web Development:** Website Development, WordPress Development, Shopify Development, E-commerce Development, Web Applications, Python / Django and Business Websites.
- **App & Software:** App Development, Custom Software, Database Applications and Business Software.
- **Digital Services:** Graphic Design, Canva Design, CV/Resume, PDF/Word/Excel, Online Forms, Digital Documentation and Computer Services.
- **PLC & Automation:** PLC Programming, PLC Troubleshooting, Industrial Automation, Motor Control, Control Systems, Sensor Systems and Control Panels.
- **Arduino / ESP32 / IoT:** Arduino Projects, ESP32 Projects, IoT Projects, Sensor Automation, Smart Automation, Water Tank Automation and Custom Electronics Projects.
- **IT Services:** Windows/PC Support, Software Installation, Technical Troubleshooting, Basic Networking and Software Solutions.

For every approved service, fill the main WordPress editor with a short introduction, actual problem/solution context, included items, tools, process, suitable customer, FAQ and internal links. The service template provides the CTA, related content slots and an enquiry form; it does not invent service-specific claims.

## Initial real project entry: Automatic Water Tank Controller

Create this only after confirming the actual build and use this conservative starter outline:

- **Title:** Automatic Water Tank Controller.
- **Description:** A water-level automation project that can connect water-level sensors, an Arduino or ESP32 controller, a relay and a motor/pump.
- **Document only implemented features:** automatic motor on/off, water-level detection, overflow protection, manual control and status indication. Add dry-run protection or fault/alarm handling only where those functions are genuinely implemented.
- **Required content:** actual board/sensor/relay details, wiring or safety notes where appropriate, implementation photographs or a clearly labelled no-image state, known limitations and a related Arduino/IoT service link.

Do not publish client names, results, screenshots or capabilities that have not been verified.

## Article clusters (publish after editorial review)

1. **PLC pillar:** What Is PLC Programming? → PLC vs Arduino → What Is Industrial Automation? → PLC Programming service → any verified PLC project.
2. **Arduino automation pillar:** Arduino Automatic Water Tank Controller → How Water Level Sensors Work → Arduino Relay Motor Control → ESP32 vs Arduino → Arduino / IoT service → verified Water Tank project.
3. **Business web pillar:** WordPress vs Shopify → How to Build a Business Website → How to Create a Professional WordPress Website → Web Development / WordPress service → verified portfolio work.
4. **Business growth pillar:** How to Start Selling Web Development Services → Digital Services pages. Avoid income guarantees.
5. **Beginner learning pillar:** Best Beginner Arduino Automation Projects → Arduino articles and service CTA.

Use the WordPress categories: Web Development, WordPress, Shopify, PLC, Arduino, Automation, IoT, Digital Services, Freelancing, Computer & IT, Tutorials and Technology. Add each article only when it contains a direct answer, original detail, practical steps/examples, common mistakes, visible FAQ where useful, internal links and a relevant non-spammy CTA.
